# Shrooms

I want to build a website to visualize occurences of mushrooms, to help with foraging and finding them.
It should have a large dataset of occurences and display those on a map.
Look for good ways to get a dataset, the GBIF API, iNaturalist might be useful. Your call.
You can just make a call to download the data once and process, don't have to update it every time the site is loaded or anything.

The app should have usueful features like filtering by time, type, region etc, and displaying information about specific species when selecting those. Also be mobile friendly. Theres gonna be a lot of data points (100'000+) when using datasets like GBIF, so make sure to use hardware accelerated rendering/good optimization.


USe Node.js for the backend
